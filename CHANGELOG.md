# Changelog

## 2.0.0 — 2026-08-22

- Rebuilt RepoPilot as an independent Java 21 repository governance CLI.
- Added repository snapshots with language, build-system and engineering-signal detection.
- Added Git diff risk scoring for security, migrations, CI/CD, dependencies and credentials.
- Added command/path policy decisions with allow, approval and block outcomes.
- Added repository task workflow with optimistic versioning, file locks and atomic persistence.
- Added generated Markdown evidence reports and review checklists.
- Reduced runtime dependencies to Jackson and removed the prototype Agent runtime integration.
- Added standalone shaded JAR, smoke verification, CI and release automation.
