# Security policy

Supported security fixes target the latest `2.x` release.

Report vulnerabilities privately through the repository's GitHub Security Advisory page. Do not open a public issue containing an exploit, credential or private repository path.

RepoPilot runs locally and writes state under `.repopilot/`. It does not upload source code or enable telemetry. Policy output is decision support; callers remain responsible for authentication, reviewer identity and process isolation when integrating the CLI into automation.
