# Project history

RepoPilot 2.0 is an independent repository change-governance CLI maintained by [pravinkaveya473-sketch](https://github.com/pravinkaveya473-sketch).

An earlier private prototype experimented with integrating governance controls into a third-party coding-agent runtime. That runtime and its resources are not part of the RepoPilot 2.0 source tree, build, binary or public release history. Version 2.0 replaced the prototype architecture with a focused implementation covering repository inspection, risk analysis, command/path policy, governed tasks and evidence reporting.

This note is retained to describe the engineering evolution accurately. Claims about RepoPilot 2.0 should refer only to the capabilities implemented and tested in the current repository.
